Добавлена полноценная поддержка FreeBSD и openSUSE — и для установки с ISO, и для cloud-образов, с DHCP и статическим IP.

Новые роли
freebsd/ — freebsd/tasks/main.yml, freebsd/README.md

Автоматизация через bsdinstall script: генерируется installerconfig (preamble + chroot-скрипт).
xorriso ремастит копию disc1 ISO, добавляя /etc/installerconfig; оригинал не изменяется.
VM грузится через virt-install --cdrom + --boot hd,cdrom (для FreeBSD --location не работает). Финальный домен автоматически грузится с диска, без цикла переустановки.
Настраиваются hostname, DHCP/статический IP (sysrc/ifconfig_vtnet0), DNS, timezone, sshd, пользователь в wheel, SSH-ключ, root lock, sudo NOPASSWD (best-effort через pkg, т.к. в базовой FreeBSD sudo нет).
opensuse/ — opensuse/tasks/main.yml, opensuse/README.md

Автоматизация через AutoYaST: генерируется autoinst.xml (LVM на весь диск, пользователи, пакеты, sshd, chroot-скрипты).
Профиль упаковывается в ISO с меткой OEMDRV; boot-аргумент autoyast=label://OEMDRV/autoinst.xml.
Загрузка через --location с явными kernel=boot/x86_64/loader/linux,initrd=boot/x86_64/loader/initrd.
Сеть: DHCP или static через linuxrc ifcfg=eth*=..., с переносом в установленную систему (keep_install_network).
Отключён firewall, root залочен, пользователь с sudo NOPASSWD и SSH-ключом.
Cloud-режим
cloud/defaults/main.yml и cloud/tasks/main.yml теперь используют переменную cloud_user_data с вариантами:

Linux (rhel/ubuntu/debian/opensuse): bash, sudo NOPASSWD, netplan для static; для openSUSE — ifcfg/wicked + zypper install sudo;
FreeBSD: /bin/sh, sudo через pkg, sudoers в /usr/local/etc/sudoers.d, static через sysrc/rc.conf.
Поддержан новый способ install_mode: cloud для любого os_family, при этом старый os_family: cloud сохранён. ОС определяется по имени cloud_image (cloud_os_effective) либо задаётся через cloud_os. Обновлены актуальные URL: FreeBSD 15.1 BASIC-CLOUDINIT и openSUSE Leap 15.6 NoCloud.

Общие изменения
install_vm.yml — добавлены boot_mode (location/cdrom) и location_opts.
create_vm.yml — install_mode_effective, cloud_os_effective, детект FreeBSD/openSUSE по Volume ID, диспетчеризация ISO/cloud-ролей.
vars.yml, ansible.cfg, README.md, cloud/README.md — документация и параметры обновлены.
Проверки
Успешно выполнены: ansible-playbook --syntax-check, YAML-парсинг всех файлов, рендеринг и XML-валидация autoinst.xml, sh -n для installerconfig, YAML-валидация cloud user-data для FreeBSD/openSUSE/Linux, детект ISO по Volume ID, проверка boot order через virt-install --print-xml и тестовый ремастеринг через xorriso.

Ограничения: для FreeBSD sudo ставится best-effort (нужна сеть); статическая сеть openSUSE в cloud-режиме настраивается best-effort через ifcfg/wicked.
